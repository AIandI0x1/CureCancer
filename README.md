# CureCancer

An open, long-running public effort to **cure cancer** — open research, open data, reproducible science, public collaboration.

> **This goal completes only when cancer is actually cured** — no proxy metric, publication count, repo activity, or model result substitutes for that verdict. Everything here is scaffolding toward that one outcome.

## Why this exists

Cancer still kills ~10 million people a year. Progress is fragmented across paywalled papers, irreproducible pipelines, and siloed datasets. This repo is a standing public surface where that fragmentation gets repaired in the open, one reproducible artifact at a time.

## Principles

1. **Open by default.** Research, data handling, and methods live here in the open. No silent progress.
2. **Reproducible or it didn't happen.** Pinned data, pinned deps, one-command runs.
3. **Evidence over claims.** Every result links its data, code, and run log. Prose describing work is not work.
4. **Patients first.** If a choice trades rigor for speed of appearance, choose rigor — the people this serves cannot afford theater.
5. **Compounding.** Each phase builds on the last. Small durable artifacts beat grand announcements.

## How to contribute

- Read `CONTRIBUTING.md` for the workflow.
- Read `ROADMAP.md` for where we are and what's next.
- Open an issue to propose a workstream; open a PR to land one.
- Every PR must link data + code + reproduction steps.
